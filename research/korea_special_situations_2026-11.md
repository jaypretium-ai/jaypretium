# Korea Special Situations: 오해받는 성장 옵션 + 저밸류 후보군 (2026-11-03)

## 0. 전제 / 데이터 한계
- 기준 패턴: **좋은 core 펀더멘털 + 시장이 아직 반영 안 한 신규 성장 옵션 + 낮은 밸류(PER/EV/PBR)** + 촉매(출시, 배당, 행동주의, 사업 재분류)
- **밸류 수치는 실시간 데이터가 아님**: 2025-2026 상반기까지 공개 정보 기반 추정 범위. 주가 급등으로 이미 rerating 끝난 종목 섞여 있을 수 있음 → DART/FnGuide로 시총·순현금·컨센 EPS 재검증 필수
- 행동주의/지분 이벤트는 기억 기반, 일부 불확실 → `(검증)` 표시
- 확신도: A = 구조 명확 + 촉매 있음 / B = 구조 맞으나 촉매·밸류 확인 필요 / C = 옵션성 위주

## 3. Devil's advocate (전체 리스트 관점)
- **"Misunderstood" ≠ "Mispriced"**: 상당수(웹젠, 레이언스, 신도리코, 대한약품, 인포바인)는 시장이 오해한 게 아니라 **자본배분 불신**을 정확히 가격에 반영 → 촉매 없으면 value trap. 순현금만 보고 사면 5-10년 횡보 가능
- **테마 선반영**: 비나텍/삼화전기/지엔씨에너지/헥토파이낸셜/씨어스는 2025-26 테마 랠리로 이미 rerating됐을 가능성 → 현재가 기준 PER 재확인 필수 (확신 C 이하로 둔 이유)
- **신사업 비중 문제**: 신사업이 매출의 10% 미만이면 멀티플 전환 불가 (대웅 더마, 삼익THK 로봇). 동국제약/솔루엠은 신사업 비중 30%+ 넘어가며 rerating됐음 → **신사업 비중 20-30% 임계점** 근처 종목 우선
- **지주 할인**: 상법 개정(충실의무/집중투표) 이후에도 지주 할인 해소는 일부만 진행 → NAV 할인 축소 가정은 보수적으로 (60% → 45-50% 수준)
- **유동성**: 시총 1,000억 미만은 진입/청산 슬리피지가 기대수익 상당부분 잠식
- **매크로**: 코스닥 성장주 장세가 반도체 쏠림 해소 가정에 의존 → 반도체 재집중 시 소형주 언더퍼폼
