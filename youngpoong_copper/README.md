# 영풍(000670) 주가 vs 구리 가격 — 수준·YoY 차트

영풍 종가와 구리(USD/t)를 (1) 공통 시작일=100 인덱스, (2) 소형 다중 패널(수준), (3) 일별·월별 YoY,
(4) 월별 YoY 산점도로 그린다. 이중 y축은 쓰지 않는다(축 정렬이 임의라서 상관을 "만들어" 보이므로).

## 실행

```bash
pip install -r requirements.txt
python main.py --start 2023-01-01            # 온라인(pykrx→FDR→yfinance / HG=F→FRED) 실패 시 오프라인 스냅샷 자동 대체
python main.py --source offline              # 네트워크 없이 ./data 스냅샷만 사용
```

출력: `output/01_indexed_levels.png`, `02_levels_small_multiples.png`, `03_yoy.png`, `04_yoy_scatter.png`,
`summary.txt`(요약 통계 + 월별 YoY 표), `monthly.csv`.

## 오프라인 스냅샷 (2026-09-22 기준) — 출처·한계

| 파일 | 내용 | 출처 | 비고 |
|---|---|---|---|
| `data/youngpoong_000670_close.csv` | 영풍 일별 종가 2023-01-02~2026-09-21 (826일) | KRX 일별 시세 공개 미러 3종 | `source` 컬럼에 구간별 출처 기재 |
| `data/copper_usd_daily.csv` | 구리 USD/t 2021-02-04~2026-09-21 | COMEX HG=F(~2026-02-04) + 중국 현물(VAT 제외, USDCNY 환산)을 60일 중첩 비율(1.016)로 splice | `copper_source` 컬럼으로 구분 |

- **영풍 액면분할(10:1, 2025)**: 2025-04-07 이전 원시 종가는 /10 조정. 조정 후 2025-04-07 34,750원 → 2025-08-07 42,150원으로 연속성 확인.
- **영풍 결측 구간 2025-04-08~2025-08-06**: 접근 가능한 공개 소스 없음. 차트에서 회색 음영, 월별 YoY 는 해당 4개월(2025-04~07)과 그 1년 후(2026-04~07) 모두 NaN 처리(부분 월을 월말값으로 쓰지 않음).
- 2025-08-07~2026-08-06 구간(KRX OpenAPI 미러)은 네이버 기반 2차 소스와 88/88 일 일치 검증.
- 구리 COMEX 는 2025-07 미국 관세 프리미엄으로 LME 대비 급등·급락(7/8 +12,445 → 7/31 9,547)이 있음. LME 기준으로 보려면 온라인 모드에서 FRED `PCOPPUSDM`(월별) 로 대체.
- 최신 월(2026-09)은 월중(MTD) 값.
