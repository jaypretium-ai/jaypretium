# 삼성전자 보통주(005930) vs 우선주(005935) 괴리율 백테스트

`005930`(보통주)과 `005935`(우선주)의 일별 **할인율(괴리율)** 시계열을 실제 데이터로 구축하고,
"할인율이 X% 이상일 때 우선주를 사면 N개월 후 상대수익률은?"을 **통계적으로 정직하게** 검증한다.

> 이 도구의 목적은 "이기는 전략"을 파는 것이 아니라, **분포와 표본 한계를 있는 그대로 보여주는 것**이다.
> 그럴듯한 단일 승률 숫자(예: "승률 90%")는 의도적으로 전면에 내세우지 않는다.

## 핵심 정의

- **할인율(%)** = `(보통주_close − 우선주_close) / 보통주_close × 100`
- **상대수익률** = `우선주 수익률 − 보통주 수익률` ← 괴리율 전략의 **진짜 알파**.
  (시장 전체가 올라서 우선주가 오른 것과, 괴리 축소로 우선주가 보통주보다 더 오른 것은 다르다.
  단순 우선주 수익률이 아니라 이 상대수익률을 봐야 한다.)
- **할인 축소 여부** = `진입 할인율 − 청산 할인율` (양수 = 괴리 축소).

## ⚠️ 통계 함정 — 결과 해석 시 반드시 읽을 것

이 백테스트는 **쉽게 과적합(overfit)된 장밋빛 결론**을 낼 수 있는 구조다. 아래를 항상 같이 보라.

1. **Overlapping window 편향 (가장 중요)**
   일별로 진입을 잡으면 인접한 진입일들은 거의 같은 미래 구간을 공유한다. 즉
   `n_days`(관측 수)는 **독립 표본이 아니다.** 같은 한 번의 괴리 확대 국면이 수백 개의
   "가짜 표본"으로 부풀려진다. 그래서 본 도구는 **`n_episodes`(독립 에피소드 = 할인율이
   임계값을 상향 돌파한 distinct cluster 수)** 를 함께 보고한다.
   **결론은 반드시 `n_episodes` 기준으로 해석하라.** `n_days`가 600이어도 에피소드가
   5개면, 그건 "5번의 사건"을 본 것이다.

2. **승률 단독 사용 금지**
   `win%` 하나로 판단하지 말 것. 평균·중앙값·표준편차·5/25/50/75/95 백분위·
   최악(worst)·최선(best)을 **모두** 출력한다. 평균이 양(+)이어도 worst가 −15%면
   "반반에 가까운 도박"일 수 있다.

3. **표본이 작으면 일반화 금지**
   독립 에피소드 `< 5` 인 버킷은 콘솔에 `⚠표본<5` 와 경고를 띄운다.
   (예: 35% 임계값은 역사적으로 매우 드물어 에피소드가 한 줌뿐이다. 100% 승률이 떠도
   그것은 전략의 기대값이 아니라 **몇 번의 특정 국면**일 뿐이다.)

4. **회귀(mean-reversion)는 공짜가 아니다 — catalyst가 원인이었다**
   "할인율이 높다 → 반드시 좁혀진다"는 **틀린 인과**다. 과거 괴리 축소에는 대부분
   **배당정책/수급 catalyst**가 있었다:
   - **2018년 배당 확대**(삼성전자 주주환원 정책 강화) 국면에서 고배당 매력이 큰 우선주가
     상대적으로 강세 → 괴리 축소.
   - **2021년 특별배당**(특별배당금 지급) 전후 우선주 수요 증가.
   - 그 외 자사주 소각·분기배당 도입 등 정책 이벤트.

   catalyst 없이 "할인율 숫자만 높으니 회귀가 확실"하다고 보면 안 된다.
   괴리는 **catalyst가 없으면 수년간 넓은 채로 유지**될 수 있다(우선주 유동성/지수편입
   불리 등 구조적 할인 요인 존재).

5. **Look-ahead(미래 데이터 누수) 차단**
   forward return은 진입일 **이후** 가격만 사용한다. 진입일+window 가 데이터 끝을 넘어가면
   해당 진입은 제외한다(truncation). 따라서 최근 구간일수록 긴 윈도우 표본이 줄어든다 —
   이는 버그가 아니라 누수를 막기 위한 정상 동작이다.

6. **가짜 정밀도 금지**
   표시는 소수점 1자리까지만. (CSV에는 분석 편의를 위해 더 보존하지만, 의사결정 숫자는
   1자리 이상 신뢰하지 말 것.)

## 데이터 정제 규칙

- 수정주가 사용. **2018-05 액면분할(50:1)**: pykrx `adjusted=True` / FDR 모두 분할 반영가를
  제공한다. 그래도 `data.py`가 분할 구간의 비정상 가격 점프(하루 60%↑)를 검사해
  **미조정 데이터면 경고**한다.
- 두 종목 **거래일 교집합(inner join)** 으로 정렬, 결측치는 **forward fill 금지·drop**.

## 결론을 쓸 때의 태도

- "할인율 X%에서 사면 6개월 뒤 평균 +Y%" 같은 문장을 쓰기 전에,
  그 표본의 **독립 에피소드 수**와 **worst-case**를 같은 문장에 적어라.
- 양(+)의 기대값이 보여도, 그것이 **특정 배당 catalyst 국면에 몰려 있는지**
  산점도/연도별 표로 확인하라. 몰려 있다면 "전략"이 아니라 "그 사건"을 본 것이다.
